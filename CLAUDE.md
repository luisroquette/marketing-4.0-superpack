# MARKETING 4.0 Superpack — agent guidance

This repo is a manual and an assembly map, not a runtime. To onboard a
non-technical owner into the pack (inventory → recipe → gated assembly), use
the bundled project skill `marketing40-onboarding`
(`.claude/skills/marketing40-onboarding/SKILL.md`). It auto-loads when Claude
Code runs inside this repo; to use it elsewhere, copy the folder to
`~/.claude/skills/`.

Do not edit `README.md` or `docs/` without owner approval — the README is
the public manual and the docs are its contracts.
